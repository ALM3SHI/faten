# 📤 سكريبت رفع التحديثات على GitHub

## الملفات المتضمنة:
- **upload_to_github.ps1** - السكريبت الرئيسي (PowerShell)
- **upload_github.bat** - ملف تشغيل سهل (ينقر مرة واحدة فقط)

## طريقة الاستخدام:

### الطريقة الأسهل (نقرة واحدة):
1. انقر مرتين على ملف `upload_github.bat`
2. اتبع التعليمات التي تظهر

### الطريقة اليدويّة (من PowerShell):
```powershell
.\upload_to_github.ps1
```

## ماذا يفعل السكريبت؟
1. ✓ يتحقق من وجود تغييرات جديدة
2. ✓ يعرض قائمة التغييرات
3. ✓ يطلب منك تأكيد الرفع
4. ✓ يطلب منك وصف التحديث
5. ✓ يرفع كل شيء على GitHub تلقائياً

## أمثلة على الرسائل:
- `إضافة ميزة جديدة`
- `إصلاح خطأ في التنقل`
- `تحديث الواجهة`
- أي وصف تريده!
